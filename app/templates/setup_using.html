How it works

Paste a long URL and create a short one on {{ public_host }}. Visits go straight to the destination. Nothing is counted.

Creating a link

Leave slug empty for four random characters, like {{ public_host }}/a3kx. Type a slug if you want a path of your own, like {{ public_host }}/launch.

Slug prefix

Optional, off by default. In Settings you can add a prefix to every new link, for example suite_ → {{ public_host }}/suite_a3kx. Changing the prefix later does not rewrite existing links.

Managing links

Open a row to edit or copy. Tick links and delete the selection, or delete everything older than a period you choose.
