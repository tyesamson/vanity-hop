Point DNS at this server

Do this at whichever registrar or DNS host holds {{ dns_host }}. The labels vary; the records do not.

  1. Sign in to the place that manages DNS for this domain (registrar, Cloudflare, your host, etc.).
  2. Open DNS records for the zone. For {{ dns_host }} that is usually the parent domain.
  3. Add a record for the host you want:
    • Subdomain (for example links.example.com): CNAME for links to the hostname of the machine running your reverse proxy, or an A record to its IPv4 address (and AAAA for IPv6).
    • Apex / root domain (for example example.com): A / AAAA, or ALIAS / ANAME if the DNS host supports it. CNAME on the apex is often invalid.
  4. Wait for DNS. It can be seconds or a few hours.
  5. Put HTTPS in front of this app so the public origin is exactly {{ public_origin }}. If you use Nginx Proxy Manager: add a Proxy Host for {{ dns_host }} pointing at this container (scheme HTTP, forward hostname on), then request an SSL certificate and enable Force SSL.
